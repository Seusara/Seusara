## 👨‍💻 Sobre mí

Soy estudiante de **Ingeniería en Desarrollo de Software en la UTLD** y cofundador de **Comar-K Tecnología**. Diseño, desarrollo y despliego sistemas web completos para negocios reales de La Laguna, desde la base de datos y el backend hasta la experiencia final del usuario.

Mi trabajo incluye sistemas de punto de venta, inventarios, CRM, catálogos digitales, gestión de pedidos y automatizaciones.

- 🔭 Mantengo **5 proyectos en producción** utilizados activamente por negocios reales.
- 🧩 Trabajo principalmente con **React, TypeScript, Supabase y Vercel**.
- ⚙️ Continúo profundizando en arquitectura de software y automatización con **n8n**.
- 🌙 Disponible para colaborar en horario vespertino y nocturno.
