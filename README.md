### 👨‍💻 Sobre mí

Estudiante de Ingeniería en Desarrollo de Software (UTLD) y co-fundador de **Comar-K Tecnología**. Diseño y despliego sistemas web de producción de extremo a extremo — base de datos, backend y frontend — para negocios reales de La Laguna: gestión de pedidos, POS, CRM, catálogos e inventarios.

- 🔭 Actualmente doy mantenimiento a **5 proyectos en producción** usados activamente por negocios reales.
- 🌱 Aprendiendo constantemente sobre arquitectura de sistemas y automatización (**n8n**).
- 🕒 Disponible en horario vespertino/nocturno.
